# Publisher slug fonts

This directory contains 30 curated typefaces used by the Partner Video
Repackager: 15 Devanagari-focused newsroom faces and 15 English editorial
faces. The font files come from the [Google Fonts](https://github.com/google/fonts)
repository and are bundled so local previews and Cloud Run exports use the
same typography.

The fonts are distributed under the SIL Open Font License, except Roboto Slab,
whose bundled Apache license is included separately. See `OFL.txt` and
`RobotoSlab-LICENSE.txt`.
